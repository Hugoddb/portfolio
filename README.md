# 🖥️ Portfolio

An interactive portfolio inspired by a desktop operating system, built with **React** and **Vite**.

Instead of a traditional single-page portfolio, this project recreates a desktop environment where each folder opens a dedicated application window presenting my profile, projects, skills, experience and contact information.

## ✨ Features

- 🖥️ Desktop-inspired user interface
- 📁 Interactive folders
- 🪟 Custom themed windows
- 👤 About section
- 💼 Professional experience timeline
- 🚀 Interactive projects gallery
- 🛠️ Skills categorized by domain
- 💻 Terminal-inspired contact window
- 📄 Downloadable CV
- 📱 Responsive layout
- ⚡ Built with Vite

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Hugoddb/Portfolio.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
